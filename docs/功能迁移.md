# 功能迁移与行为修正

基线为独立 `chaoxing` 仓库的 `dfc99da09890eac24e9c8406b3ce9371e68d2db3`。历史实现仅用于对照接口行为和修正场景；运行时不依赖两个旧仓库，也不读取旧账号、日志或数据库。

| 旧功能 | Courseflow 中的实现 |
| --- | --- |
| 账号密码／持久 Cookie | 模块提供密码登录；宿主维护加密会话和账号隔离，不从旧 Cookie 文件直接登录 |
| 扫码登录 | 保留二维码、手机确认、课程域落地和身份核对 |
| 课程文件夹、任务点与先修锁 | 分页枚举文件夹、章节及多张卡片，未解锁章节给出原因，完成先修任务后可刷新 |
| 视频与音频 | 播放信息优先使用移动端接口，旧状态接口兜底；保留截取窗口、秒／毫秒区分、上报间隔和签名 |
| 播放开始、拖动、完成 | 分短步骤发送相应事件；仅平台允许且管理员启用时拖动；以平台确认完成为准 |
| 文档、阅读、空章节 | 保留任务上报，非 JSON 响应通过官方卡片／章节目录回读确认 |
| 直播 | 迁移直播状态和 `saveTimePc` 观看记录；不猜测三十分钟时长，不以本地计时冒充完成 |
| 章节测验 | 五类题型、原作答、字体解码、草稿、确认交卷与回读；不通过重新开卷查看已提交试卷 |
| 言溪、TikuAdapter、TikuLike | 协议适配拆至独立题库 SDK，由调用方注入请求与私有配置；本模块不内置外部题库配置或自动选择供应商 |
| AI／视觉模型 | 框架模型接口及题图代理；任务可关闭 AI 并人工补答 |
| 本地答案缓存 | 宿主加密题库按用户、平台、课程隔离；候选答案不自动标成正确 |
| CLI、旧 Web UI、多用户、日志与并发 | 使用框架统一界面、账号、队列、任务报告和日志导出，不在模块重复启动服务 |
| 通知、题库余额／轮换 token、旧配置文件 | 不移植旧管理界面；题库接口向调用方开放，配置和限额由宿主管理 |
| 自动 OCR 验证码、随机选项兜底 | 遇验证或缺失答案时暂停，由用户处理；不会猜测答案后交卷 |

## 保留的协议修正

- 作业卡片的 `isPassed` 不能单独证明测验已交卷，优先核对平台任务完成列表。
- 平台返回 `stuStatus=5` 时表示低于通过线，转人工处理，不自动重新提交。
- 移动端 `playTime` 是秒，卡片 `playTime` 是毫秒；暂停后重新取得平台位置，不累计暂停时长。
- `vbegin/vend` 决定播放窗口和签名的 `clipTime`；保留完整 `otherInfo` 和额外时长／人脸签名字段。
- 部分接口没有 `mid` 时使用附件编号或旧状态接口兜底；可选移动接口失败不直接判定登录过期。
- 选项优先读取 `aria-label`，移除选择提示；乱码、未知表单和教师未完成测验时停止自动作答。
- 开卷与交卷前保存意图，网络结果未知时不重发；回读必须确认原作答。

## 当前验证边界

只有离线假宿主和合成数据的端到端验证，没有使用真实账号。验证码、人脸、未开放任务、正式考试以及平台协议变化均需要用户在官方页面处理。已提交测验保留原任务报告；当前不提供重新打开平台试卷的复核或重做入口。
